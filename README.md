# iPad Trackpad: aggiornamenti

Qui ci sono solo le **versioni pronte** di iPad Trackpad (lo zip allegato a ogni release) e `appcast.xml`, l'elenco che l'app legge
per **aggiornarsi da sola** con Sparkle. Gli zip sono firmati: l'app installa solo quelli con la firma giusta.

Il codice sta in un repository privato; si pubblica con `publish_update.py` del progetto.
